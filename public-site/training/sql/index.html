Data Analysis Using SQL

What I learned

Use SQL queries to turn data into evidence: filter records, join related tables, group results, and calculate summaries. The focus was learning to ask useful questions, explore patterns, and test whether query results support an insight.

Practical work

August 2024. Practical querying exercises explored datasets from different angles, compared subsets, and used the results to develop and refine analytical questions.

Start with a question

The exercises treated a query as a way to investigate data. We tried questions, inspected the returned records, and adjusted the query to better understand the result.

Querying for insight

Filters narrow the records being examined, joins bring related information together, and grouping with aggregation creates useful comparisons and summaries. The goal was to explain an observation using the data returned by the query.
