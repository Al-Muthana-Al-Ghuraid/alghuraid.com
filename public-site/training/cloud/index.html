What I learned

Practical Microsoft Azure training covering infrastructure as code, containers, deployment automation and cloud security. The capstone connected an application to cloud storage, data services and deployment pipelines.

Infrastructure and deployment

Training combined Terraform infrastructure, Docker containers and GitHub Actions delivery pipelines. Deployment exercises covered VM Scale Sets, AKS and Azure Container Apps.

Services used in the capstone

The capstone combined Streamlit, FastAPI and ChromaDB with services for documents, application data and secrets: Blob Storage, PostgreSQL, Cosmos DB and Key Vault. OpenMetadata formed a separate governance workstream.

Connecting the pieces

A practical challenge was connecting VM Scale Set instances to ChromaDB on a separate VM. Correcting the service’s network binding made it reachable and clarified how application configuration and cloud networking work together.
