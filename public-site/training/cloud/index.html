Infrastructure and deployment

The bootcamp covered Microsoft Azure infrastructure, Terraform, containerization with Docker, and deployment automation through GitHub Actions. Practical work included VM Scale Sets, AKS, and Azure Container Apps, connecting application delivery with cloud operations.

Services used in the capstone

The RAG chatbot brought together Streamlit, FastAPI, and ChromaDB with Azure services for documents, application data, and secrets: Blob Storage, PostgreSQL, Cosmos DB, and Key Vault. The project also included a related OpenMetadata deployment.

Connecting the pieces

A practical challenge involved connecting VM Scale Set instances to ChromaDB on a separate VM. Fixing the service’s network binding made it reachable from the application instances and reinforced how application configuration and cloud networking interact.
