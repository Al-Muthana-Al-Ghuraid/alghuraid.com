TrackFlow — Bootcamp Management Platform

TrackFlow brings cohort administration, learning activities, help-session booking and progress monitoring into one application. I led a three-person team and worked across the frontend, backend and database.

Training project with demonstration data. The diagrams show how the application’s modules interact.

Application architecture

Four user roles use a React interface backed by FastAPI. JWT authentication and backend permission checks control access. Application modules share a SQLite database through SQLAlchemy, and FastAPI serves uploaded files.

Learning and progress

Progress reporting combines learning and attendance records using bulk cohort queries instead of separate queries for every student.

Help-session booking

Recurring availability templates define bookable sessions. Booking checks cover the student’s role and cohort, active bookings, booking restrictions and slot availability. Session statuses include completion, cancellation and no-shows.
