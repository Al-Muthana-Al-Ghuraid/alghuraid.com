Azure RAG Chatbot

A PDF-based assistant with Streamlit, FastAPI, and ChromaDB retrieval, deployed on Azure using Terraform and GitHub Actions. I implemented the application, deployment, pipelines, and the related OpenMetadata workstream.

VM Scale Set deployment

Application Gateway routes requests to Streamlit and FastAPI on VM Scale Sets. The application connects to PostgreSQL, Blob Storage, Key Vault, and ChromaDB on a separate VM. The presentation documents fixing ChromaDB network binding so the VMSS instances could reach it.
