Azure RAG Chatbot

A team project that answers questions from PDF documents using Streamlit, FastAPI and ChromaDB. I contributed across the application, Azure deployment with Terraform, GitHub Actions pipelines and the related OpenMetadata workstream.

The project included separate VM Scale Set and Container Apps deployments. AKS was also used.

VM Scale Set deployment

Application Gateway routes requests to Streamlit and FastAPI on VM Scale Sets. The application uses PostgreSQL, Blob Storage and Key Vault, with ChromaDB running on a separate VM. Correcting ChromaDB’s network binding allowed the application instances to reach it.

Container deployment variant

Azure Container Apps runs the containerized application in this deployment. Container Registry and GitHub Actions support delivery; the design also includes a Streamlit/ChromaDB VM, PostgreSQL, Blob Storage, Key Vault and Cosmos DB.

Related OpenMetadata deployment

OpenMetadata was deployed on an Azure VM using Docker Compose and MySQL as a related governance component. It is presented separately from the chatbot’s retrieval path.
