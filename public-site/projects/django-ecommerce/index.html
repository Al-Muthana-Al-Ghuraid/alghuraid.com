Django E-commerce Platform

An end-to-end training project built during Tuwaiq Academy’s Django program. I built shopper pages and store administration around a shared relational model, with authentication, carts, coupons, and order flow.

Conceptual architecture based on the implemented store features. Original application screenshots are not included.

Store architecture

Shoppers use HTML, CSS, and Bootstrap templates. Staff use store administration. Both connect to Django application features and shared data through the Django ORM. Accounts and permissions separate shopper and staff access.

Shopping and cart flow

Customers search or browse categories, inspect product details and reviews, add items to the cart, apply coupons, and see calculated totals before continuing through the order flow.

Store administration

Staff manage products, prices, images, descriptions, discounts, stock, item visibility, and customer reviews. The relational model covers categories, products, stock quantities, carts, orders, and reviews.
